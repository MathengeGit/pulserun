Every pixel, hand-rolled.

PulseRun is a neon obstacle runner with no graphics library underneath. Lines, circles, polygons, clipping and curves are rasterised by our own C++ into a plain array of pixels, compiled to WebAssembly, and copied onto the canvas below once per frame.

01

The pipeline

One frame, start to finish. Nothing on the right of an arrow knows anything about graphics hardware.

  1. level1.txt

    Level file

    Plain text: SPIKE 400 450. Parsed into obstacles with hitbox polygons.

  2. 60 Hz

    Physics

    Fixed timestep. Gravity, hold-to-jump, AABB broad phase, polygon narrow phase.

  3. mat3

    Camera

    A 3 × 3 homogeneous matrix maps world to screen before anything is drawn.

  4. raster/

    Rasterise

    Bresenham, midpoint circles, edge-table scanline fill, Cohen-Sutherland, De Casteljau.

  5. 960 × 540

    Framebuffer

    518 400 RGBA pixels with source-over alpha blending, nothing more.

  6. putImageData

    Present

    The bytes are copied to this canvas (or an SDL window on desktop) untouched.

How a frame is made

  1. The fixed-timestep loop advances physics in 1/60 s steps.
  2. The camera's mat3 turns world positions into screen positions.
  3. Each shape is rasterised into the framebuffer by our own algorithms.
  4. The finished pixels are copied to the canvas.

Glossary

Bresenham
Integer-only line drawing: steps one pixel at a time and tracks the error term.
Midpoint circle
Plots one octant of a circle by testing the midpoint between two candidate pixels, then mirrors it eight ways.
Scanline fill
Fills a polygon row by row using an edge table and an active edge table (even-odd rule).
Cohen-Sutherland
Clips a line to a rectangle using 4-bit outcodes to accept or reject quickly.
Sutherland-Hodgman
Clips a polygon against each window edge in turn.
De Casteljau
Evaluates a Bezier curve by repeated linear interpolation.
mat3
A 3 × 3 matrix on (x, y, 1) so translate, rotate and scale chain by multiplication.
AABB
Axis-aligned bounding box: the cheap first test before exact polygon overlap.
Fixed timestep
Physics always advances by exactly 1/60 s, so jumps are identical on every machine.
